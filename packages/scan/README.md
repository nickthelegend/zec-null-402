# scan

`zpay-verify` (Rust), copied from [zec-payment-verify-sdk](https://github.com/nickthelegend/zec-payment-verify-sdk) `packages/core` (same author, MIT). The gateway uses it to check deposits, and clients and tests use it to read anchors, with incoming viewing keys: `ZPV_UIVK=… zpay-verify verify <txid> --amount <zat> --memo <memo>`, `inspect <txid>`, `tip`, and `scan-range <from> [to]` / `scan-range --last <n>` (added here, adapted from zec-unlinkable-swaps' copy: compact-block trial decryption of Sapling, Orchard and Ironwood outputs over a block range, each hit re-read in full), which clients use to find every anchor on the anchor address in their window.
