Pay per call on Zcash without a transaction per call.

Deposit once, shielded. Then every API call carries a zero-knowledge proof of one unspent prepaid note. The gateway checks it in a few hundred milliseconds and learns that some note paid, not which one.

SourceTrust model

The live run

depositanchor two shielded transactions on testnet
20 paid calls

Replays, tampered proofs, proofs for another request and a second claim of the deposit were refused. The gateway's state is anchored in a shielded memo anyone with the published viewing key can read.

Limits

Zcash has no contracts, so the gateway runs the pool and is trusted; anchors make its history auditable. Single-party trusted setup. Testnet only.
